# Quick Start - 5 Minute NFC Setup

## 1. Get Stickers (~2 min)

Order NTAG215 or NTAG216 stickers:
- Amazon: \NTAG215 stickers\ (~\ for 100 pack)
- AliExpress: Even cheaper if you can wait 2-3 weeks

## 2. Install an App (1 min)

Pick one (all are free):
- **Android**: TagWriter by NXP, NFC Tools, or Tagg
- **iPhone**: TagWriter by NXP, Tagg, or Shortcuts app
- **Web**: Use our web app (no installation needed)

## 3. Write Your First Tag (2 min)

### Option A: Using Web App
1. Go to \web-app/index.html\ (or visit our hosted version)
2. Enter a URL (e.g., https://www.google.com)
3. Click "Write to NFC Tag"
4. Hold your phone to the sticker
5. Done!

### Option B: Using Mobile App
1. Open the app you installed
2. Tap "Write New Tag" or "New"
3. Choose \URI\ (for URLs)
4. Enter your URL
5. Hold phone to sticker
6. Confirm

## Common Issues

**"Nothing happens when I tap"**
- Is NFC enabled? Check Settings
- Try different spots on your phone (antenna location varies)
- Is the app supposed to open something? Test the URL first

**"Can't write to tag"**
- Is NFC turned ON?
- Try a different NFC app
- Some stickers come locked (try a new one)
