# Contributing to Awesome NFC

First off, thanks for thinking about contributing! 🎉

Awesome NFC is a community-driven project, and we'd love your help making it even better.

## Ways to Contribute

### 1. **Add Awesome Resources**
Found a cool NFC library, tutorial, or project? Submit it!

- Make sure it's actually awesome (active, well-documented, solves real problems)
- Add it to the relevant section in README.md
- Include a brief description of what makes it cool

### 2. **Improve Documentation**
- Fix typos or unclear explanations
- Add new guides or tutorials
- Improve code examples
- Update outdated information

### 3. **Report Issues**
- Found a broken link? Let us know
- Spotted inaccurate info? Open an issue
- Have an idea? Suggest it!

### 4. **Share Your Projects**
Built something cool with NFC? We'd love to feature it in the Examples section.

## How to Contribute

1. **Fork the repo** - Click the fork button on GitHub
2. **Clone your fork** - \git clone https://github.com/your-username/awesome-nfc.git\
3. **Create a branch** - \git checkout -b feature/your-awesome-thing\
4. **Make your changes** - Edit files, add resources, fix bugs
5. **Commit** - \git commit -m "Add awesome NFC resource"\
6. **Push** - \git push origin feature/your-awesome-thing\
7. **Open a PR** - Describe what you added and why

## Guidelines

### For Adding Libraries/Tools
- ✅ Active development (updated in last 12 months)
- ✅ Well-documented with clear examples
- ✅ Solves a real problem
- ✅ Works with standard NFC protocols
- ❌ No spam or self-promotion-only links
- ❌ No abandoned/dead projects

### For Adding Tutorials/Guides
- ✅ Clear, beginner-friendly explanations
- ✅ Working code examples
- ✅ Accurate technical information
- ✅ Links to official documentation
- ❌ No outdated info
- ❌ No misleading titles

### For Adding Projects
- ✅ Real, working projects (not concepts)
- ✅ Source code or detailed documentation available
- ✅ Clear use case demonstrated
- ✅ Reproducible by others
- ❌ No commercial spam
- ❌ No projects that encourage harmful uses

## Code of Conduct

- Be respectful to everyone
- No harassment or discrimination
- Constructive criticism only
- Help beginners learn
- Share knowledge freely

## Questions?

- Check existing issues first
- Ask in GitHub Discussions
- Email the maintainers

## Recognition

All contributors are credited. By contributing, you're part of building the best NFC resource on the internet! 🚀
